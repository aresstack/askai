# AskAI Wizard Illustrations – v3

Six individual transparent PNG illustrations for the AskAI setup wizard.

## Design reference

The character follows the supplied AskAI logo/banner wizard:
- pointed midnight-blue hood with ornate gold edging
- completely black, faceless hood interior
- dark navy/black robe with detailed gold embroidery
- glowing lowercase `sk` chest mark
- blue gemstone in an ornate gold belt clasp
- photorealistic, dimensional fantasy illustration with blue shadows and warm gold light

The character identity is kept consistent across the set. The poses vary, but the costume, hood, emblem, belt and visual language remain aligned with the supplied reference.

## Staff design

Whenever visible, the staff remains straight and slender with a dark/gold shaft and a bright sparkler-like golden flame at the top. The flame and sparks may vary; the staff silhouette does not.

## Transparency and usage

- All six individual files are PNGs with an alpha channel.
- Use the individual PNGs in the wizard; do not use the preview or sprite sheet as UI assets.
- Preserve aspect ratio when scaling.
- The preview JPG uses a checkerboard background only to demonstrate transparency.
