Java 21

Alles zum neuen LTS-Release

19. September 2023

Heute erscheint Java 21, das neue Long-Term-Support-Release. In dieser Folge sprechen zwei Kollegen darüber, welche Neuerungen im Alltag den größten Unterschied machen und welche Features das Arbeiten auf der JVM erleichtern.

Virtual Threads machen blockierenden Code wieder skalierbar, ohne dass Anwendungen auf reaktive Bibliotheken umgestellt werden müssen. Structured Concurrency fasst zusammengehörige Aufgaben zu einer Einheit zusammen, deren Fehler und Abbrüche gemeinsam behandelt werden.

Scoped Values ersetzen in vielen Fällen ThreadLocal und passen besser zu Millionen kurzlebiger Threads. Record Patterns und Pattern Matching für switch machen datenorientierten Code kürzer und lesbarer.

Dazu kommen Sequenced Collections mit einer einheitlichen Schnittstelle für geordnete Sammlungen, der generationale Z Garbage Collector, unbenannte Muster und Variablen sowie String Templates als Vorschau.

Wer von Java 17 kommt, sollte außerdem die Änderungen bei der Finalisierung, das dynamische Laden von Agents und UTF-8 als Standardzeichensatz im Blick behalten. Die Shownotes verlinken die zugehörigen JEPs.
